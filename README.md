🐄 QurbaniHat Livestock

A modern livestock booking platform built with Next.js, designed to help users browse, explore, and discover animals for Qurbani and farming needs through a smooth and interactive experience.

🌐 Live Demo: https://b13-a8-qurbani-hat.vercel.app





🎯 Project Purpose

QurbaniHat Livestock aims to simplify the process of exploring and selecting livestock by providing a clean, user-friendly interface where users can:

Browse available animals with ease
View detailed animal information
Sort animals by price (low to high / high to low)
Explore featured breeds
Enjoy smooth and modern UI interactions





✨ Key Features

🐄 Animal Management
Animal listing page with clean card-based UI
Dedicated animal details page with full information
Featured animals section for highlights

🔍 User Experience
Smooth navigation with Next.js App Router
Fully responsive design (mobile, tablet, desktop)
Interactive and animated UI elements

💰 Sorting & Filtering
Sort animals by price (Low → High / High → Low)
Structured layout for better browsing experience

🎨 UI & Animation
Modern UI built with Tailwind CSS
Smooth animations using React Spring
Scroll-based animations with Intersection Observer

🔐 Authentication UI
Sign in / Sign up pages
Profile UI structure (frontend-ready)
