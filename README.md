🐄 QurbaniHat Livestock

A modern livestock booking platform built with Next.js, allowing users to browse, view, and explore animals for Qurbani and farming needs.

🌐 Live URL

👉 https://b13-a8-qurbani-hat.vercel.app

🎯 Project Purpose

The purpose of this project is to create a simple and user-friendly platform where users can:

Browse available animals
View detailed animal information
Sort animals by price
Explore featured breeds
Enjoy smooth UI animations


✨ Key Features
🐄 Animal listing page with cards
🔍 Animal details page
💰 Sort animals by price (Low → High / High → Low)
⭐ Featured animals section
🎨 Animated UI using React Spring
📱 Fully responsive design (mobile, tablet, desktop)
🔐 Authentication UI (Sign in / Sign up / Profile)
⚡ Fast performance with Next.js App Router
